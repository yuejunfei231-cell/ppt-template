## 重新生成 / 修改

```bash
pip install python-pptx Pillow pymupdf   # pymupdf 仅用于抽取预览中文字体
python3 build.py                # 全量：pptx + 预览
python3 build.py --only 05-kinetics   # 只渲染单页调试
```

- `slides.py` —— 10 页的版式与文字（改内容/坐标在这里）
- `deckkit/layout.py` —— 版式引擎：换行、行高、对齐、化学式上下标、曲线采样
- `deckkit/to_pptx.py` —— 渲染为可编辑 PPTX（含项目符号、上下标、阴影、渐变 XML）
- `deckkit/to_png.py` —— 渲染为 PNG 预览（与 PPTX 同一套坐标，用于校对）
- `deckkit/cjk_preview.ttf` —— 预览用中文字体（Droid Sans Fallback，Apache 协议），
  缺失时 `build.py` 会自动从 PyMuPDF 内置字体抽取；**不入库**

## 字体与配色

- PPT 内中文：`Microsoft YaHei`（微软雅黑），西文/数字：`Arial`（两台系统通用，无需嵌字体）
- 主色：学术深蓝 `#0F3D6E`；强调：青绿 `#12A08C`
- 氮素形态语义色（全篇统一）：NH₄⁺ 橙 `#DD8A2B`、NO₂⁻ 红 `#C6434B`、NO₃⁻ 绿 `#2E9A5B`、N₂/TN 蓝 `#1C5590/#2A6FB0`

## 使用提示

- 首页与尾页的 `[你的名字] / [导师名字] / 202X年X月X日` 为占位符，直接在 PowerPoint 里替换即可。

  插入 Origin/Excel 图表。
